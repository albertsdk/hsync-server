# Support

## How to get help

- **[FAQ](docs/faq.md)** — answers to common questions and troubleshooting tips.
- **[Documentation](docs/README.md)** — complete documentation index: deployment, operations, API reference, security, and more.
- **[GitHub Issues](https://github.com/albertsdk/hsync-server/issues)** — bug reports and feature requests. Please search existing issues before opening a new one.
- **[GitHub Discussions](https://github.com/albertsdk/hsync-server/discussions)** — community questions, ideas, and general discussion.
- **[Security Policy](SECURITY.md)** — how to report security vulnerabilities privately.

## Before asking for help

1. Check the [FAQ](docs/faq.md) — your question may already be answered.
2. Check the [documentation](docs/README.md) — the deployment, operations, and troubleshooting guides cover common issues.
3. Enable debug logging (`HSYNC_LOG_LEVEL=debug`) and check your logs for error messages.
4. Verify your configuration: `HSYNC_API_KEY` must be set, the bucket directory must exist and be writable.

## 💚 Solo project

HSYNC is developed entirely by a single person in their spare time. Feature requests, bug reports, and pull requests are reviewed as soon as possible, but response times may vary. The developer does their best to maintain and improve the project — thank you for your patience and support!
